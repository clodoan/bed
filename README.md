# Bed

A Mac menu-bar radio for free curated internet stations — SomaFM's deep house /
downtempo / lounge channels, and Nightride synthwave. No account, no API key.
Skip cycles stations. These are donation-supported —
[somafm.com](https://somafm.com) and [nightride.fm](https://nightride.fm).

## Install

Download **Bed.app.zip** from the
[latest release](https://github.com/clodoan/bed/releases/latest).
That is the app. Do not use **Source code (zip)** — that is just the repo.

Unzip, drag `Bed.app` into `/Applications`, then **right-click → Open** the
first time (unsigned). Apple Silicon, macOS 14+.

```sh
./scripts/package.sh
```
